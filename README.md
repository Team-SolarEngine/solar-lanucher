## How to use;
Just open the app. In the top right, you have a plus. Then you can put the following;
- App name
- App URL icon
- Execute command
- Working directory

Once you've filled all of them, you can click `Add App`, and you can start the app. On the side of the Start button, you have multiple selection. You have;
- Open as Admin
- Edit
- Delete
- Open Folder
