# Contributing for Solar Launcher
Thank you for your time for contributing! Here's guidelines we appricate you to follow.

## Submitting a Pull Request
### THE DON'Ts
- **DO NOT SEND AI SLOP.**
  - This heavily defects our code quality and maintainability. If you are caught sending AI slop, we will reject your pull request, and ban you from the repository.
- Don't rush perfection.
  - Don't give us one-liners that 60% of coders won't figure out what the fuck the code does. 
- Injecting malware.
  - Fuck you.
- Unmaintainable and low-quality code.
  - We will reject any pull request that does not meet our standards for maintainability and quality. Please for the love of god write maintainable and quality code. Not some shitty code that nobody can read.

### THE DO's
- Actually useful code that solves a problem.
  - Code that actually does someting useful. For example, adding a new feature, fixing a bug, or improving performance.
- Give code enough context with comments.
  - Give new contributors or maintainers enough context with comments so they can understand what the code does.
- Test before submitting.
  - Test your code before submitting a pull request. We don't want to merge broken code. A bonus skill issue if you can't test your code.

## Submitting an Issue
### THE DON'Ts
- Submitting a non-existing issue
  - Creating a issue that doesn't exist. Double check if the issue you're having persists, and then submit a Issue.
- Duplicate issues
  - Search for a existing issue first, and then submit a issue if one doesn't exist.

### THE DO's
- Submit a clear and concise issue title and description.
  - Use a clear and concise title that summarizes the issue.
